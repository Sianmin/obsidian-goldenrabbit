
# QMD 

- QMD 설치
```bash
npm install -g @tobilu/qmd
```

- QMD collection 추가 및 임베딩

```bash
qmd collection add . --name PKM
qmd embed
qmd status
```

- QMD 결과 확인
```bash
qmd vsearch "zettelkasten" --files
```

# 번외 - 윈도우에서 QMD 설정

전반적으로 macos와 동일합니다. 

1. 우선 Node.js 설치가 필요합니다. MacOS에서의 설치와 마찬가지로 [Node.js 홈페이지](https://nodejs.org/en/download)에 접속해서 다운로드 해주세요.
![[Pasted image 20260322143613.png]]

2. Powershell은 관리자 권한으로 실행해주세요. 그 후, 다음 명령어를 입력합니다.
```powershell
Set-ExecutionPolicy RemoteSigned
```
![[20260322054014.png]]
![[20260322054149.png]]
3. npm으로 설치한 qmd는 macOS/Linux용으로 만들어져 있어서 PowerShell에서 바로 실행되지 않습니다. Windows가 인식할 수 있는 실행 파일(.cmd)를 직접 만들어 qmd 명령어가 동작하도록 다음 명령을 입력합니다. (혹시 Powershell이 아닌 WSL에서 진행하신 분들은 진행할 필요는 없습니다.)
```powershell
Set-Content "$env:APPDATA\npm\qmd.ps1" '& node "$env:APPDATA\npm\node_modules\@tobilu\qmd\dist\cli\qmd.js" $args'
```

이후 `qmd` 명령어를 입력해 다음 스크린샷과 같이 qmd 설명이 뜨는지 확인합니다. 이후 과정은 qmd collection 추가 파트부터 동일하게 macos랑 진행하면 됩니다.
