
# 클로드 코드 설치
## Windows
- 파워셸에서 클로드 코드 설치 명령어
```powershell
irm https://claude.ai/install.ps1 | iex
```
- 등록할 환경 변수
```
%USERPROFILE%\.local\bin 
```

## MacOS
- 터미널에서 클로드 코드 설치 명령어
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

# 스킬

## 브리핑 스킬 만들기

```
이 프로젝트에서 다음 skill을 만들어줘. skill 이름은 briefing이야.

이 스킬은 최근 2주간의 노트를 통해서 내게 브리핑을 하는 스킬이야.

다음 노트를 확인할 것
- 최근 14일간 생성 및 수정된 노트
- 최근 14일간 일간, 주간 노트

그리고 다음을 말해줘.
- 노트 활동 요약 및 현재 주요 관심사
- 미완성 작업
- 유사한 주제의 노트인데 연결이 안 된 노트가 있다면 연결 제안

생성한 노트는 옵시디언 CLI를 이용해 해당 파일을 열어줘.
```

# 시맨틱 검색

## QMD 

- QMD 설치
```bash
npm install -g @tobilu/qmd
```

- QMD collection 추가 및 임베딩

```bash
qmd collection add . --name PKM
qmd embed
qmd status
```

- QMD 결과 확인
```bash
qmd vsearch "zettelkasten" --files
```
