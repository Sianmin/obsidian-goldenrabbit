# 볼트 브리핑 스킬

당신은 사용자의 옵시디언 볼트에서 최근 2주간의 활동을 분석하여 브리핑을 제공하는 어시스턴트입니다.

## 1단계: 최근 노트 수집

오늘 날짜를 기준으로 최근 14일간의 노트를 수집하세요.

### 1-1. 일간 노트 수집

`3. Resource/periodic notes/daily/` 폴더에서 최근 14일간의 일간 노트를 읽으세요.

- 파일명 패턴: `YYYY-MM-DD.md`
- 오늘부터 14일 전까지의 날짜에 해당하는 파일을 Glob으로 찾고, Read로 읽으세요.

### 1-2. 주간 노트 수집

`3. Resource/periodic notes/weekly/` 폴더에서 최근 2~3주간의 주간 노트를 읽으세요.

- 파일명 패턴: `YYYY-Www.md` (예: `2026-W07.md`)
- 해당 기간에 포함되는 주간 노트를 Glob으로 찾고 Read로 읽으세요.

### 1-3. 최근 생성/수정된 노트 수집

다음 방법으로 최근 14일간 생성 또는 수정된 노트를 찾으세요.

```bash
find . -name "*.md" -not -path "*/.obsidian/*" -not -path "*/.claude/*" -not -path "*/.git/*" -mtime -14 -type f
```

- `.obsidian/`, `.claude/` 등 설정 폴더는 제외합니다.
- 수집된 노트의 제목과 경로를 정리합니다.
- 노트 수가 많을 경우 주요 노트의 내용만 선별적으로 읽으세요.

## 2단계: 노트 분석

수집한 노트들을 분석하여 다음 정보를 도출하세요.

### 2-1. 노트 활동 요약 및 주요 관심사

- 최근 2주간 생성/수정된 노트 수, 일간/주간 노트 현황
- 어떤 폴더(Slip-box, Projects, Area, Resource, Books 등)에서 활동이 많았는지
- 노트 내용에서 반복적으로 등장하는 **주제, 키워드, 태그**를 추출하여 현재 주요 관심사를 파악

### 2-2. 미완성 작업

일간/주간 노트와 기타 노트에서 미완성 작업을 찾으세요:

- 체크박스 미완료 항목: `- [ ]` 패턴
- "TODO", "할 일", "해야 할", "예정" 등의 키워드가 포함된 항목
- 진행 중인 프로젝트나 계획 관련 내용

### 2-3. 연결 제안

QMD 검색 도구를 활용하여 연결되지 않은 관련 노트를 찾으세요:

1. 최근 노트에서 핵심 주제/키워드를 추출합니다.
2. `mcp__qmd__vector_search`를 사용하여 의미적으로 유사한 노트를 검색합니다.
   - collection: "pkm"으로 제한
3. 검색 결과 중 최근 노트에서 `[[위키링크]]`로 연결되어 있지 않은 노트를 찾습니다.
4. 실제로 연결할 가치가 있는 조합만 선별하여 제안합니다 (최대 5개).

## 3단계: 브리핑 노트 작성

`3. Resource/periodic notes/daily/` 폴더에 브리핑 노트를 생성하세요.

- 파일명: `{오늘날짜}-briefing.md` (예: `2026-02-23-briefing.md`)
- 이미 같은 이름의 파일이 있으면 덮어쓰세요.

노트 본문 형식:

```markdown
# 노트 활동 요약

{최근 2주간 노트 활동 통계 및 요약}
- 생성/수정된 노트: N개
- 활발한 영역: ...
- 일간 노트 작성일: ...

# 현재 주요 관심사

{반복적으로 등장하는 주제와 키워드를 바탕으로 정리}

1. **주제1** — 설명
2. **주제2** — 설명
3. ...

# 미완성 작업

{미완료 체크박스, TODO 등을 출처 노트와 함께 정리}

- [ ] 작업 내용 — 출처: [[노트 이름]]
- [ ] 작업 내용 — 출처: [[노트 이름]]

# 연결 제안

{유사한 주제인데 연결되지 않은 노트 쌍을 제안}

| 노트 A | 노트 B | 연결 이유 |
|--------|--------|-----------|
| [[노트1]] | [[노트2]] | 이유 설명 |
```

## 4단계: 노트 열기

브리핑 노트 작성이 완료되면 obsidian CLI를 사용하여 생성한 노트를 옵시디언에서 열어주세요.

```bash
obsidian open path="3. Resource/periodic notes/daily/{오늘날짜}-briefing.md"
```

## 5단계: 구두 브리핑

노트를 열고 난 뒤, 사용자에게 브리핑 내용을 간결하게 요약하여 말해주세요:

- 핵심 활동 요약 (1~2문장)
- 주요 관심사 (키워드 나열)
- 미완성 작업 중 주요 항목
- 연결 제안 하이라이트

## 주의사항

- 모든 내용은 **한국어**로 작성하세요.
- 노트를 언급할 때는 `[[위키링크]]` 형식을 사용하세요.
- 병렬 처리가 가능한 검색/읽기 작업은 Task 도구를 활용하여 병렬로 수행하세요.
- 미완성 작업은 이미 완료 표시(`- [x]`)된 항목을 포함하지 마세요.
- 연결 제안은 억지스러운 연결을 피하고, 실질적으로 도움이 되는 것만 포함하세요.
- 노트가 매우 많을 경우 모든 노트를 읽으려 하지 말고, 제목과 구조를 보고 핵심 노트만 선별적으로 읽으세요.
